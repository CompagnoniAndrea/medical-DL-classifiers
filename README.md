## 🚀 Come Iniziare

1. **Apri il notebook** `Copia di Pirati_AI.ipynb`
2. **Cerca la sezione** "🔍 Autocorrelation Analysis for Optimal Window Size"
3. **Esegui le celle** per analizzare i tuoi dati
4. **Leggi i risultati** e aggiorna `WINDOW_SIZE` e `STRIDE`
5. **Addestra il modello** con parametri ottimizzati

Per dettagli completi, consulta **[QUICK_START.md](QUICK_START.md)**
